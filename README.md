# MiniChainSupply 🧱🚚
A simple blockchain-based supply chain tracking web app built with Flask and Python.

## 🔍 Overview
This project demonstrates the core concepts of a blockchain by allowing users to track updates in a supply chain. Each input becomes a new block with:
- Timestamp
- SHA256 hash
- Previous hash reference

I created this while starting to learn **Algorand blockchain** to understand how blockchains work under the hood. This is a basic prototype of a blockchain-backed application.

## 🛠️ Features
- Add supply chain entries as blocks
- View the full blockchain chain
- Each block includes:
  - Index
  - Timestamp
  - Data
  - Hash and previous hash
